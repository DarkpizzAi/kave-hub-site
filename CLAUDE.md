# Non-negotiables

- This repo is public. No household data, names, figures or tokens, ever.
- The icons (`favicon.svg`, `favicon-32.png`, `icon-512.png`,
  `apple-touch-icon.png`) come from kave-hub's `brand/icons/hub/`, drawn by
  `brand/tools/make_app_icons.py`. Never hand-edit them: regenerate and copy.
- No service worker, no manifest. Window sizes as the apps (Material 3): the
  rail from 840 up, the top bar's menu and one column below.
- No em or en dashes. British spelling.
- Deploy order: content repo first, then this one. Only `main` deploys.
- `m3/` (the Material 3 kit and tokens) is generated by kave-hub's `brand/tools/sync-household-tokens.py`.
  Never hand-edit it. The whole site is on it since 06/11/2026 (css/site.css is layout only).
- `js/guard.js` lists every site file in `FILES` for the stale-module recovery.
  Add each new module there in the same commit.

## The household look is enforced

Before any interface change, load `brand:apply-household-look` (or read
`kave-hub/brand/skills/apply-household-look/SKILL.md` if the loaded copy is
out of date). Every commit runs `kave-hub/brand/tools/brand_check.py --strict`
(git hook and Claude hook), and pushing `main` needs a passed brand review in
`kave-hub/brand/reviews/<this repo>-<VERSION>.md`. A deviation from Material 3
needs Isa's dated decision in `kave-hub/brand/data/look-recap.md`.
